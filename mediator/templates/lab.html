4 · Communication between the data sources

  • Mediator → every source: POST /query (parameterised SELECT, parallel).
  • Mediator → Ministry: POST /reports writes a counterfeit report back.
  • Ministry → Distributor: POST /flag-supplier — a confirmed counterfeit report auto-blacklists the named supplier in the distributor DB.
  • All traffic is JSON over HTTP; no source can read another source's database file.
